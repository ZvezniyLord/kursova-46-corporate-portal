# Зразки курсу — очікують дозволеного отримання

Ця директорія призначена для оригінальних прикладів/матеріалів, які дозволено поширювати. Наразі двійкові файли Moodle тут відсутні: прямий доступ до ресурсів переспрямовував на вхід, тому їхній вміст не був отриманий і не додається під виглядом зразків.

Офіційні сторінки/ресурси:
- [Статут ІТ-проєкту — Moodle](https://dist.nupp.edu.ua/mod/resource/view.php?id=453690)
- [Навчальний приклад — Moodle](https://dist.nupp.edu.ua/mod/resource/view.php?id=263043)
- [Матриця зацікавлених сторін — Moodle](https://dist.nupp.edu.ua/mod/resource/view.php?id=263740)
- [Зразки лабораторних матеріалів — Moodle](https://dist.nupp.edu.ua/course/view.php?id=3729)

Після отримання файлу від користувача або легального публічного URL перевірити зміст, назву, метадані та дозвіл на публікацію. Видалити особисті дані студентів та викладачів, якщо вони не потрібні для навчальної мети.
