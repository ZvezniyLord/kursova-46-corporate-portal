# Курсова робота №46 — корпоративний портал підприємства

Репозиторій для систематизації вимог курсу, методичних матеріалів і робочих артефактів курсової роботи зі спеціальності 122 «Комп’ютерні науки».

**Тема:** «Управління ІТ-проєктом створення корпоративного порталу підприємства».

> Публічний репозиторій: файли, які тут розміщені, доступні будь-кому. У навчальних матеріалах можуть бути авторські права та персональні дані — перед публікацією сторонніх файлів перевірте умови поширення та видаліть непотрібні персональні дані. Оригінали LMS-зразків сюди не включаються без підтвердження дозволу на публічне поширення; замість них наведено офіційні посилання й власні робочі шаблони.

## Ключові вимоги з офіційної сторінки курсу

- Усі розділи виконуються на прикладі одного ІТ-проєкту й мають бути узгодженими між собою.
- Потрібні власні розрахунки, схеми, графіки та обґрунтування управлінських рішень; пояснювальна записка має містити практичні результати, а не переважно теорію.
- Microsoft Project — календарний, ресурсний і вартісний план; обов’язковий результат — `.mpp` із календарем, ресурсами, бюджетом, Baseline та даними моніторингу.
- Jira — для завдань та моделювання Agile-процесів.
- Дозволені змодельовані фактичні дані, але припущення потрібно явно описати.
- Джерела треба цитувати згідно з академічною доброчесністю.

Детальна робоча структура: [`docs/structure-and-requirements.md`](docs/structure-and-requirements.md).

## Зовнішні методичні джерела

- PMI, [Do More in Less](https://www.pmi.org/learning/library/eight-project-management-processes-9362) — статут, реєстр зацікавлених сторін, WBS, календарний план, комунікації, ризики, звітування.
- Microsoft Support, [Track progress](https://support.microsoft.com/en-us/project/project-management-goal-track-progress) та [Create/update a baseline](https://support.microsoft.com/en-us/project/create-or-update-a-baseline-or-an-interim-plan-in-project-desktop).
- Atlassian, [Learn Scrum with Jira](https://www.atlassian.com/agile/tutorials/how-to-do-scrum-with-jira) — backlog, user stories, спринти.
- OWASP, [Application Security Verification Standard](https://owasp.org/www-project-developer-guide/release/security_gap_analysis/guides/application_security_verification_standard/) — перевірка безпеки вебзастосунку.
- ISO, [ISO 15489-1:2016 Records management](https://www.iso.org/standard/62542.html) — принципи керування документованою інформацією.

## Структура репозиторію

- `docs/` — вимоги та рекомендований зміст роботи.
- `templates/` — авторські шаблони робочих артефактів; це не оригінальні форми Moodle.
- `sources/` — бібліографічні посилання/реєстр джерел.
- `samples/` — зарезервовано для зразків, які дозволено публічно поширювати.

## Відповідальне використання

Не завантажуйте сюди дані для входу, персональні дані студентів, матеріали з обмеженим доступом або авторські матеріали без дозволу. Публічний репозиторій — не місце для секретів та приватних навчальних даних.
