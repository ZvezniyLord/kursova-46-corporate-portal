# Модель планування — відкриті параметри сценарію

**Стан: EDUCATIONAL_SIMULATION;** детальний графік згенеровано з реєстру робіт нижче. Дати, години, ставки USD, прогрес і витрати — синтетичні припущення, не погоджені параметри підприємства й не затверджений baseline. Відтворення: `python 01-project-plan/build/build_dataset.py`. Реальні календарні обмеження, ресурсна спроможність, обґрунтування оцінок і погодження залишаються відкритими; нативний `.mpp` не створено.

| Вхід | Визначення / сценарій | Стан |
|---|---|---|
| Робочий календар | Пн–пт, початок 2026-09-07, 80 робочих днів; свята не враховані | EDUCATIONAL_SIMULATION |
| Оцінки робіт | 24 роботи з тривалістю та FS-залежностями у `tasks.csv` | EDUCATIONAL_SIMULATION |
| Ресурсна спроможність | Синтетичні ролі/години у `resources.csv`; реальні люди не підтверджені | EDUCATIONAL_SIMULATION |
| Ставки й модель вартості | Умовні USD/год; лише трудові витрати, без фіксованих витрат і резерву | EDUCATIONAL_SIMULATION |
| Baseline | Пропозиція Baseline 0 у `baseline.csv`; не затверджено | DRAFT |
| Дата EVM | 45-й робочий день, 2026-11-06; умовний прогрес/витрати для кожної роботи | EDUCATIONAL_SIMULATION |
| PV/EV/AC | PV планова вартість; EV і AC модельовані на рівні робіт | EDUCATIONAL_SIMULATION |
| Відхилення/індекси | SV=EV-PV; CV=EV-AC; SPI=EV/PV; CPI=EV/AC; нульові знаменники порожні | REPRODUCIBLE |

Не подавати графік, ставки, витрати, прогрес чи EVM як факти підприємства. CSV/XML не є нативним `.mpp`.
