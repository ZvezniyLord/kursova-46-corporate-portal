## Мета курсової

Формування практичних навичок комплексного управління ІТ-проєктом через розроблення проєктної документації, обґрунтування рішень, календарне, ресурсне та вартісне планування у Microsoft Project, командну роботу в Jira, моделювання виконання, моніторинг та аналіз результативності.

## Обов’язкові правила

1. Усі розділи присвячені одному обраному проєкту.
2. Подавати власні аналітичні висновки, розрахунки, схеми, графіки й обґрунтування управлінських рішень.
3. Microsoft Project використовувати для календарного, ресурсного та вартісного планування.
4. Jira використовувати для завдань і моделювання Agile-процесів.
5. Змодельовані фактичні дані дозволені за умови явного опису припущень.
6. Планування і контроль мають бути взаємопов’язаними.
7. Обов’язково здати файл Microsoft Project (`.mpp`) із календарем, ресурсами, бюджетом, Baseline і моніторинговими даними.
8. Пояснювальна записка має показувати практичну роботу, а не переважно теоретичний огляд.
9. Цитувати джерела відповідно до академічної доброчесності.

## Рекомендована структура

### Вступ
Обґрунтувати актуальність; визначити мету й завдання, очікувані результати та практичну цінність.

### Розділ 1. Ініціація та організаційне обґрунтування

#### 1.1. Концепція та статут
- Проблема й бізнес-потреба.
- SMART-мета.
- Очікувані результати, обмеження, критерії успіху.
- Project Charter.

#### 1.2. Зацікавлені сторони та вимоги
- Stakeholder Register.
- Power–Interest matrix.
- Функціональні й нефункціональні вимоги.
- User Stories та Acceptance Criteria.

#### 1.3. Методологія та структура управління
- Порівняння Waterfall, Scrum, Kanban і гібридного підходу.
- Обґрунтування вибору.
- Життєвий цикл, пріоритизований Product Backlog.
- Команда, ролі, RACI та план комунікацій.

### Розділ 2. Планування змісту, строків, ресурсів і вартості

#### 2.1. Зміст та календарний план
- Project Scope та Scope Statement.
- WBS, work packages, milestones.
- Послідовність, залежності й тривалості робіт.
- Календар у Microsoft Project і діаграма Ганта.

#### 2.2. Ресурси, бюджет та оптимізація в Microsoft Project
- Ресурси, характеристики, ставки/вартість використання.
- Призначення ресурсів; аналіз завантаження та перевантажень.
- Трудомісткість, вартість робіт і бюджет.
- Оптимізація плану; збереження Baseline.

#### 2.3. Організація виконання в Jira
- Створити проєкт і Scrum- або Kanban-дошку.
- Створити Epic, User Story, Task, Sub-task.
- Пріоритети, статуси, виконавці.
- Для Scrum — Sprint Backlog; описати командну взаємодію.

### Розділ 3. Моделювання, моніторинг та оцінювання

#### 3.1. Ризики, якість і зміни
- Класифікувати ризики та сформувати Risk Register.
- Оцінити ймовірність/вплив і побудувати Probability–Impact Matrix.
- Стратегії реагування й власники ризиків.
- Критерії якості та Definition of Done.
- Change Request із аналізом впливу на зміст, строки, бюджет і якість.

#### 3.2. Виконання та моніторинг
- Змоделювати виконання частини робіт.
- Для Scrum запланувати Sprint, відстежити роботу у Jira й оцінити результат.
- Внести фактичні дані в Microsoft Project.
- Порівняти план/факт строків, витрат і ресурсів; визначити відхилення від Baseline.
- Розрахувати CPI та SPI на основі EVM.
- Проаналізувати Agile-метрики/звіти Jira та сформувати Project Status Report.

#### 3.3. Оцінювання і завершення
- Причини відхилень і коригувальні рішення.
- Досягнення цілей і критерії успіху.
- Приймання результату замовником.
- Project Closure Report, Lessons Learned, Retrospective.
- Очікувана практична цінність.

### Висновки
Узагальнити результати, ефективність планування й управління, обґрунтувати рішення та визначити можливості вдосконалення.

### Список джерел і додатки
У додатки виносити великі таблиці, схеми, детальні календарні/ресурсні плани, матриці, реєстри, звіти Microsoft Project і скриншоти Jira.
