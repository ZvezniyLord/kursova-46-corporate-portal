# Moodle: збирання методичних матеріалів для Codex

Курс: https://dist.nupp.edu.ua/course/view.php?id=3729

## Матеріали, які потрібно перевірити

1. **Мета і обов'язкові вимоги:** https://dist.nupp.edu.ua/mod/page/view.php?id=455875 — у тому числі обов'язковий нативний `.mpp` та практична Jira.
2. **Три розділи курсової:** https://dist.nupp.edu.ua/mod/page/view.php?id=455874 — повний перелік підпунктів 1.1–3.3, висновки, джерела, додатки. За копією користувача, оновлено 11.11.2026.
3. **Тема №46:** https://dist.nupp.edu.ua/mod/page/view.php?id=292756.
4. **47 навчальних тем:** https://dist.nupp.edu.ua/mod/page/view.php?id=310832 — загальна теорія; життєві цикли; статут; ризики; WBS; календар, Microsoft Project; команда й регламент; бюджет і контракти; Jira.
5. **«Сітьове планування» (DOCX):** методика залежностей FS/SS/FF/SF, ES/EF/LS/LF, float, критичного шляху, діаграми Ганта, PERT. Користувач надав файл у чаті, але це НЕ означає, що він автоматично доступний у локальному робочому каталозі Codex.
6. **«Регламент робочої проєктної групи» (PDF):** стор. 1–4, відповідальність Замовника/Виконавця, щоденна координація о 09:00, щотижневий звіт, щомісячний акт, протоколювання відхилень, погодження змін. Файл надано в чаті; Codex має отримати його через браузер Moodle або дозволене вкладення.
7. **Інші лабораторні й шаблони:** пройти **всі видимі секції саме цього курсу**, включно з прихованими за розгортанням сторінками та вкладеннями, до яких є авторизований доступ.

## Облік матеріалів

Для кожного знайденого джерела записати назву, URL, секцію, дату, тип, доступність, місце локального збереження, що саме з нього застосовано до курсової. Для відсутнього доступу — `BLOCKED`; не вигадувати зміст.

**Згода власника:** власник дозволив збирання доступних йому Moodle-матеріалів і розглядає приватний режим GitHub за необхідності. Це **не дозвіл правовласника на публічне перепоширення**. До публічного Git класти власні конспекти, назви, посилання й авторські результати; викладацькі PDF/DOCX без дозволу на відкрите поширення зберігати локально або в дозволеному приватному сховищі. Не публікувати чужі персональні дані, паролі, токени. Не вимагати створення нового репозиторію.

## Узгоджена методика

- **Курсова** — один проєкт корпоративного порталу підприємства, а не 47 окремих робіт.
- Для кожної лабораторної в інвентаризації вказати, який метод/результат використано в конкретному підрозділі та додатку.
- Не перетворювати застарілі приклади промислових проєктів на «доказ» виконання IT-порталу.
- Розділи Moodle мають пріоритет над старими чернетками, випадковими онлайн-шаблонами та агентськими інструкціями.
