# Матеріали для створення курсової №46 (публічний набір)

Ця добірка отримана після відбору **57 Markdown-файлів** з особистого Obsidian Vault. До публічного репозиторію перенесено **7 змістовних документів**, потрібних для розроблення власної версії курсової. Не копіювалися порожні заготовки, дублікати, старі інструкції для програмної курсової, внутрішні шляхи та службові записи. Оригінали Moodle і приватна база Obsidian не публікувалися.

## Вихідні дані

- **Тема:** «Управління ІТ-проєктом створення корпоративного порталу підприємства».
- **Дисципліна:** «Управління ІТ-проєктами».
- **Здобувач:** Галенко Віталій Олександрович, група 404ТН (повне ПІБ і групу надав сам здобувач; у Moodle в переліку тем зазначено «Галенко Віталій»).
- **Спеціальність:** 122 «Комп’ютерні науки».
- **Заклад:** Національний університет «Полтавська політехніка імені Юрія Кондратюка».
- **Автор Moodle-курсу:** Кузьменко Олександра Костянтинівна. **Її роль саме як керівника курсової не підтверджено.**
- **Межі завдання:** управління ІТ-проєктом, а не розроблення та демонстрація програмного прототипу.

## Найважливіші правила для іншої моделі

- Спиратися на вимоги Moodle, а не на застарілі структурні заготовки.
- Підготувати **самостійну версію** курсової з трьома основними розділами: ініціація; планування зі MS Project/Jira; моніторинг, ризики, EVM і завершення.
- У всіх розділах використовувати один сценарій, одну WBS, календар, ресурси, ставки, бюджет, Baseline та узгоджені значення PV, EV, AC, CPI, SPI.
- Умовні дані підприємства, 100 користувачів і 16 тижнів позначати як **навчальні припущення**. Грошовий бюджет у вихідних матеріалах не підтверджено.
- **Обов'язковий практичний результат:** файл Microsoft Project `.mpp` з графіком, ресурсами, бюджетом, Baseline та моніторингом. Jira використовується для завдань/Agile. Не заявляти, що артефакти створено, доки їх не перевірено.
- Керівник курсової, індивідуальний варіант, обсяг сторінок, титульний шаблон і повні вимоги робочої програми 2026 ще не встановлені.
- Робоча програма Moodle (ID 300754) та ключові лекції були знайдені, **але ще не прочитані**. Відсутні відомості не вигадувати.
- Текст українською мовою, без зайвих шаблонних фраз і без довгого тире, із доброчесним використанням перевірених джерел та дотриманням правил закладу щодо ШІ.

## Статус готовності

Матеріали придатні для підготовки незалежної академічної чернетки, але **не є завершеною курсовою**. До подання потрібно перевірити робочу програму, створити практичні артефакти MS Project та Jira, підтвердити форматування, розрахунки, джерела і правила оформлення. Нічого не надсилати до Moodle без окремого доручення.
