# Перевірені вимоги курсової

Сторінки: [основні вимоги, ID 455875](https://dist.nupp.edu.ua/mod/page/view.php?id=455875), [рекомендована структура, ID 455874](https://dist.nupp.edu.ua/mod/page/view.php?id=455874), [список тем, ID 292756](https://dist.nupp.edu.ua/mod/page/view.php?id=292756). Переглянуто 2026-11-22.

## Тема й дисципліна

У списку тем є: «Управління ІТ-проєктом створення корпоративного порталу підприємства. Галенко Віталій». Повне ПІБ і група 404ТН — зі слів здобувача. Це тема, а не назва дисципліни. Дисципліна — «Управління ІТ-проєктами».

## Обов’язкові умови

- Усі розділи виконати на прикладі одного наскрізного ІТ-проєкту.
- Подати власні аналізи, розрахунки, схеми, графіки та обґрунтування рішень.
- Microsoft Project — календарне, ресурсне й вартісне планування; обов’язковий `.mpp` із планом, ресурсами, бюджетом, Baseline та моніторингом.
- Jira — організація завдань і моделювання Agile-процесів.
- Можна застосувати змодельовані фактичні дані, але явно назвати всі припущення.
- Узгодити результати планування й контролю між собою.
- Пояснювальна записка має відображати практичну роботу, а не бути переважно теоретичною.
- Цитувати використані джерела за правилами академічної доброчесності.

## Рекомендована структура

**Вступ:** актуальність, мета, завдання, очікувані результати, практична цінність.

**Розділ 1. Ініціація та організаційне обґрунтування:** бізнес-потреба, SMART-мета, результати, обмеження, критерії успіху, Project Charter; реєстр зацікавлених сторін, Power–Interest, вимоги, User Stories та Acceptance Criteria; порівняння методологій, життєвий цикл, backlog, команда, RACI, комунікації.

**Розділ 2. Планування змісту, строків, ресурсів і вартості:** Scope/Scope Statement, WBS, робочі пакети та контрольні точки, залежності/тривалості, календар і Гант у MS Project; ресурси, ставки, завантаження, вартість і бюджет, оптимізація, Baseline; Jira-проєкт, Scrum/Kanban дошка, Epic/Story/Task/Sub-task і Sprint Backlog за обраною методологією.

**Розділ 3. Моделювання, моніторинг та оцінювання:** реєстр/матриця ризиків і реакції; якість/Definition of Done; Change Request та вплив; змодельоване виконання, план-факт і відхилення від Baseline, EVM CPI/SPI і доречні Agile-метрики, Project Status Report; коригувальні рішення, приймання, Project Closure Report, Lessons Learned/Retrospective.

**Завершення:** висновки, використані джерела, додатки з великими планами, матрицями, реєстрами та звітами.

## Не встановлено перевіреними сторінками

Точний обсяг сторінок, шаблон титульного аркуша і повний стиль оформлення треба уточнити за робочою програмою/методичкою 2026 або у викладача. Робочу програму (Moodle ID 300754) ще треба завантажити й прочитати.
