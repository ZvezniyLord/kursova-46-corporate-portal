## 7. Моніторинг / EVM (внести дату статусу)

| Показник | Значення | Примітка / джерело |
|---|---:|---|
| Статусна дата | | |
| PV (Planned Value) | | Затверджений Baseline станом на дату |
| EV (Earned Value) | | Бюджетована вартість фактично виконаної роботи |
| AC (Actual Cost) | | Фактичні витрати станом на дату |
| CPI = EV / AC | | <1 — витрати перевищують зароблену вартість |
| SPI = EV / PV | | <1 — відставання від плану |
| Основні відхилення / причини | | |
| Рішення, власник, строк | | |

Якщо наведені цифри змодельовані, позначити це на видному місці та задокументувати припущення.

## 9. Project Status / Closure

**Status Report:** період; загальний статус; зроблено; наступні роботи; milestone; строки/бюджет; ризики/проблеми; рішення, відповідальні й дати.

**Closure Report:** результати й критерії приймання; підтвердження замовника; підсумки строків і вартості; передані активи/доступи/документація; відкриті питання; Lessons Learned; ретроспектива; подальша підтримка.
